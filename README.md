# 📊 DAX Notes

Este repositorio contiene notas personales sobre DAX.

## 🚀 Objetivo

Crear una biblioteca de referencia que sirva como apoyo en el estudio y en el desarrollo de proyectos de análisis de datos con Power BI.

Aquí documentaré:

- Fórmulas útiles en DAX
- Explicaciones paso a paso
- Ejemplos de aplicación

La idea es que este repositorio crezca de manera continua, incorporando nuevas notas y guías a medida que avanzo en el aprendizaje y práctica de DAX.
